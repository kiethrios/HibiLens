# Contributing

GitHub Issues are welcome for reproducible bugs, setup problems, and product feedback.
Please use the matching Issue form and include the requested app, device, and
operating-system details.

Code contributions and Pull Requests are not accepted during the soft launch.
This policy keeps the public repository aligned with reviewed releases from the
private development repository.

For a suspected security problem, follow [SECURITY.md](SECURITY.md) instead of
opening a public Issue.
