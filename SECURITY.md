# Security policy

Use GitHub's private **Report a vulnerability** form:

https://github.com/kiethrios/HibiLens/security/advisories/new

Include the affected version, device and iOS version, steps needed to reproduce
the problem, and its likely impact. Remove personal photos, account details, and
other sensitive material unless they are essential to the report.

Do not open a public Issue for a vulnerability or post security details in an
existing Issue.
